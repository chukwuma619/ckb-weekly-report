## What I shipped (high level)

1. **Agents tab (fiber-desktop)** — Added a dedicated Agents tab that polls shop APIs and auto-creates invoices; wired into `App.tsx` and `appTabs` with labels and hints. Backend Rust module (`shop_agents.rs`) exposes list/save/delete/enable commands; React hook `useShopAgents` drives the UI (`2bd5a9a`, 2026-06-06).

2. **Shop agents backend** — Implemented ~570 lines of Rust for agent persistence and shop API polling, plus Tauri command registration in `commands.rs` and `lib.rs` (`2bd5a9a`, 2026-06-06).

3. **Documentation** — Added `docs/SHOP-AGENTS.md` with usage and architecture notes; updated `docs/ARCHITECTURE.md`; created `docs/TODO-fiber-peer-pay-agent.md` to track peer-pay agent integration (`2bd5a9a`, 2026-06-06).

4. **Fiber Peer Pay scaffold** — Initial commit for the checkout monorepo: package layout, core node handlers, and project README (`90eaa80`, 2026-06-06).

5. **Fiber Studio planning (fiber-studio)** — Scoped Fiber Studio as a native desktop shell around the official [Fiber Network Node (`fnn`)](https://github.com/nervosnetwork/fiber): guided setup, node lifecycle, wallet, channels, and network views. Chose Tauri 2 + React + Vite + Tailwind; Rust backend for FNN manager, provisioning, keychain, and RPC; `fnn` fetched at build/dev time rather than vendored in git. No commits this week — first code lands 2026-06-10.
