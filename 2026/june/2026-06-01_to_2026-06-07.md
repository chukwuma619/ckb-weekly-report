## What I shipped (high level)

1. **Project definition** — Scoped Fiber Studio as a native desktop shell around the official [Fiber Network Node (`fnn`)](https://github.com/nervosnetwork/fiber): guided setup, node lifecycle, wallet, channels, and network views — local-first, keys on disk, secrets in the OS keychain.

2. **Architecture decisions** — Chose Tauri 2 + React + Vite + Tailwind for the UI stack; Rust backend modules for FNN manager, provisioning, keychain, and RPC; `fnn` fetched at build/dev time rather than vendored in git.

3. **Prototype handoff** — Documented that [`fiber-desktop`](https://github.com/chukwuma619/fiber-desktop) remains the earlier prototype; Fiber Studio is the clean-slate v1 target with task-based flows instead of the monolithic App refactor from May.
