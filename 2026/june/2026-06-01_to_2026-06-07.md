## fiber-peer-pay

**Project:** `fiber-peer-pay` — monorepo for website integrators building Fiber checkout without running `fnn`.

Github: https://github.com/chukwuma619/fiber-peer-pay

### Summary

**Bootstrapped the monorepo** with `@fiber-peer-pay/node` (order queue, agent contract, merchant auth) and `@fiber-peer-pay/react` (optional buyer checkout UI). Defined the **Fiber Desktop Agents** integration model — sellers poll your API from Desktop; your app never calls FNN directly.

**Also this week:** initial roadmap and TODO tracking, plus a working in-memory `OrderStore` and handler skeleton for the full order lifecycle.

### What I shipped (high level)

1. **Monorepo scaffold** — npm workspaces with `@fiber-peer-pay/node` and `@fiber-peer-pay/react`, shared `tsconfig.base.json`, root `package.json` build/test scripts (`90eaa80`, 2026-06-06).

2. **Node package core** — Types, `MemoryOrderStore`, handlers for create order / get order / poll jobs / submit invoice, merchant auth via `requireMerchant`, and exported handler context (`90eaa80`, 2026-06-06).

3. **React package (deferred focus)** — `FiberCheckout` component and `useFiberOrder` hook for buyer-side polling; marked as optional sugar while node package is primary (`90eaa80`, 2026-06-06).

4. **Docs & planning** — Root README with architecture sequence diagram (buyer → API → Fiber Desktop → fnn), `ROADMAP.md` phased plan, and `TODO.md` sprint tracking (`90eaa80`, 2026-06-06).

## fiber-studio

**Project:** `fiber-studio` — ground-up v1 rebuild of the Fiber Network desktop client (Tauri 2, React, Rust backend for FNN sidecar integration).

Github: https://github.com/chukwuma619/fiber-studio

### Summary

**Planning and scoping week** for the Fiber Studio v1 rebuild — no commits in the new repo yet, but the direction is locked: replace the [`fiber-desktop`](https://github.com/chukwuma619/fiber-desktop) prototype with a cleaner architecture, guided-setup-first UX, and official `fnn` bundled as a Tauri sidecar.

**Also this week:** aligned the new repo scope with the [Fiber Desktop v1 proposal](https://talk.nervos.org/t/dis-fiber-desktop-v1-ground-up-rebuild-and-launch-fnn-desktop-app/10317) on Nervos Talk.

### What I shipped (high level)

1. **Project definition** — Scoped Fiber Studio as a native desktop shell around the official [Fiber Network Node (`fnn`)](https://github.com/nervosnetwork/fiber): guided setup, node lifecycle, wallet, channels, and network views — local-first, keys on disk, secrets in the OS keychain.

2. **Architecture decisions** — Chose Tauri 2 + React + Vite + Tailwind for the UI stack; Rust backend modules for FNN manager, provisioning, keychain, and RPC; `fnn` fetched at build/dev time rather than vendored in git.
