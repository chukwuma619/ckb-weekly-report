## What I shipped (high level)

1. **RPC error handling (fiber-desktop)** — Introduced `FiberRpcError` and `rpcUserError` helpers; refactored NetworkTab, PaymentsTab, SendTab, and SetupConnectPeerPanel to show structured, user-friendly RPC messages. Extended Rust `fiber_rpc.rs` and the `useRpc` hook for formatted summaries (`09631f7`, 2026-06-10).

2. **Fiber Peer Pay enhancements** — Added multi-CPU-arch support in lockfile, new test scripts, `handleMarkPaid` handler with improved validation, and README updates for Express/Next.js/web integration. Removed deprecated Next.js helpers and clarified API docs (`5b6552c`, `9527f2a`, 2026-06-09).

3. **Fiber Studio bootstrap** — Initial Tauri + React app rebranded from prototype to **Fiber Studio**; integrated Tailwind CSS, removed legacy App.css, updated README with planned features (`1b039fc`, `1be5184`, `e2e1fc5`, 2026-06-10).

4. **Fiber Studio UI stack** — Added TanStack Router, Headless UI, clsx, motion, and Floating UI; cleaned global styles for Tailwind; applied Inter font for typography (`45fc98d`, `f38d072`, `0c59e58`, `67df878`, 2026-06-11–12).

5. **Fiber Studio FNN integration** — Setup page with FNN sidecar, `@tauri-apps/plugin-os` for platform detection, fetch-fnn script for target-specific binaries, cross-platform CI build matrix, and health-status sync on the FNN manager (`639b9e3`, `bcb617c`, `2d5fb2c`, 2026-06-12).

6. **Fiber Studio error cleanup** — Removed unused FNN error variants (missing data dir, wallet password) and simplified studio error handling (`59d4fc2`, 2026-06-12).
