1. **Setup wizard polish (fiber-studio)** — Simplified private-key import (import-only flow), added disabled states on network selection cards, defaulted to testnet, and tightened ReviewStep copy. Removed unused props across KeyFileStep, DataDirectoryStep, and SetupWizard (`2004a9a`, `0742f3b`, `0f82030`, 2026-06-15–16).

3. **FNN sidecar runtime (fiber-studio)** — Refactored `FnnManager` to use `SharedChild` for process lifecycle, added log retrieval and formatting, dynamic `NodeLogsDialog`, data-directory-aware node status/stop, and simplified YAML config template handling (`b0ba646`, `d32fcc0`, `96600e3`, `91bcd4c`, 2026-06-16).

4. **JSON-RPC layer (fiber-studio)** — Introduced `JsonRpcError`, `CkbScript`, `UdtScript`, and `UdtDep` structs; improved `fetch_node_info` / `wait_for_node_info` error reporting with deserialization tests (`45aa760`, 2026-06-18).

5. **Home dashboard + relays (fiber-studio)** — Loaded public relays from a JSON manifest, added relay connection state management in `FnnManager`, and wired new RPC commands for channels, peers, and payments into a `HomeDashboardResponse` type (`dbb878e`, 2026-06-18).

6. **FNNPay vision and scaffold (fnn-pay)** — Documented merchant-layer vision and phased roadmap (Phase 0–4); scaffolded TanStack Start web app and Hono/Bun API server with shadcn/ui components, theme toggle, and demo routes (`e2fdc84`, `fb866c4`, 2026-06-14–16).

7. **FNNPay Docker stack (fnn-pay)** — Added `docker-compose.yml` with Postgres, FNN node, server, and web services; `init-fnn-node.sh` for wallet key bootstrap; structured `/health` endpoint with DB status; `.env.example` and quick-start docs (`9573521`, 2026-06-17).
